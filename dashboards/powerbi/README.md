# Power BI Dashboard

This folder contains the Power BI dashboard for the football analytics pipeline.

The dashboard will connect to clean BigQuery tables created by dbt.

## Dashboard Data Sources

- `match_results`
- `team_performance`
- `home_away_performance`

## Planned Dashboard Pages

### 1. Season Overview

- Total matches
- Total goals
- Home wins
- Away wins
- Draws

### 2. Team Performance

- Points by team
- Wins, draws, losses
- Goals for
- Goals against
- Goal difference

### 3. Home vs Away Analysis

- Home performance by team
- Away performance by team
- Home win rate vs away win rate
