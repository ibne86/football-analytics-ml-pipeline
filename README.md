## ✨ Overview

This project demonstrates an end-to-end football analytics and machine learning pipeline.

The pipeline collects football match data from an external API, stores raw data, transforms it into clean analytics-ready tables, and prepares it for dashboard reporting and machine learning-based match prediction.

In simple terms, this project shows the full journey:

```text
raw football data → clean data → analytics tables → dashboard → ML-ready dataset
